# Estado Alpha

RolerIA llm es una Alpha experimental para partidas desechables y supervisadas.

- La narración puede contener errores de coherencia, agencia o hechos.
- La compactación puede bloquear la continuación; no se debe forzar su aceptación.
- Combate, viajes y reglas tienen un alcance explícito y limitado.
- El runtime y el modelo se instalan por separado, con configuración local verificada.
- El fallback Python no ofrece todas las operaciones interactivas.
- No se garantiza una campaña larga ni rendimiento en cualquier equipo.

El repositorio no distribuye pruebas privadas, resultados de investigación o configuraciones del mantenedor. La comprobación de fuentes no equivale a aceptación física. Consulta [INSTALL.md](INSTALL.md) y [SECURITY.md](SECURITY.md).
