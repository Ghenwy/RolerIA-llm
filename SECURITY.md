# Seguridad y privacidad

Alpha experimental: no garantiza ausencia de fallos. Ejecuta el servidor exclusivamente en `127.0.0.1`; no abras firewall, túneles ni servicios públicos.

- No publiques credenciales, información personal, configuración real, inventarios de equipo, campañas, prompts privados ni logs crudos.
- No publiques nuestros experimentos, pruebas internas, investigación o evidencias operativas.
- Usa reproducciones mínimas y ficticias; revisa el contenido antes de adjuntarlo.
- No informes una vulnerabilidad con detalles explotables o datos sensibles en una issue pública. Solicita al mantenedor un canal privado antes de enviarlos.
- Gitignore no elimina archivos ya versionados ni copias históricas. Revisa índice, historial y artefactos antes de publicar.
- No desactives hashes, procedencia, transacciones o conservación de datos para resolver un fallo.

Las instrucciones de instalación no autorizan cambios globales o publicación de datos. [Contribuir](CONTRIBUTING.md).
